Getting this into your calendar

Subscribe, do not import. An imported .ics is a copy: if a commitment is cancelled, regenerating this file cannot reach the events already sitting in your calendar's database, and they stay there forever. A subscribed URL is replaced wholesale on each poll, so a removed commitment genuinely disappears. That is the only route that retracts.

https://raw.githubusercontent.com/PipFoweraker/pdoom1/main/docs/calendar/pdoom1-commitments.ics
  • Google Calendar: Other calendars → + → From URL → paste → Add. Polls on its own schedule, commonly 8–24 h, so a same-day change may lag.
  • Apple Calendar: File → New Calendar Subscription → paste → auto-refresh Every day.
  • Outlook / Microsoft 365: Add calendar → Subscribe from web → paste.
  • Thunderbird: New Calendar → On the Network → iCalendar (ICS) → paste.
