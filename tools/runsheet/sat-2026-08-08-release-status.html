Findings that still stand

These came from reading workflow files and run history, not from the stale measurement, so the correction above does not touch them.

  • The release-to-website signal has never worked, not once. pdoom1 sends a notification at every release. The website has no listener for it, and has never once run a job from one. The send always reports success whether or not anything is listening, so our side could never tell.
