P(Doom) -- macOS

HOW TO RUN
1. EXTRACT this zip first (double-click it in Finder), then move the
   extracted P(Doom).app wherever you like (e.g. Applications).
2. First launch is blocked, because the build is not signed or notarized
   yet (alpha). How you get past it depends on your macOS version:

   macOS 15 (Sequoia) and later -- Apple REMOVED the old right-click
   shortcut, so it will not appear for you:
      a. Double-click P(Doom).app once and dismiss the warning.
      b. Open System Settings -> Privacy & Security, scroll to Security.
      c. Click "Open Anyway" next to P(Doom), and confirm.
         You may need your admin password. First launch only.

   macOS 14 (Sonoma) and earlier:
      Right-click (or Control-click) P(Doom).app -> Open -> Open.

3. If macOS still refuses ("cannot be opened" / "damaged"), clear the
   quarantine flag from a terminal:
      xattr -dr com.apple.quarantine "P(Doom).app"

WHATS IN HERE
   P(Doom).app    the game -- game data and Steam libraries live inside
                  the app bundle, so there is nothing else to keep together

HEADS UP
   The macOS build is not extensively tested yet -- expect rough edges.
   Reports are very welcome.

FEEDBACK
   Press N in game, or click "Send Feedback". Write anything -- a bug, an
   idea, or just what you thought. When you save it the game offers three
   one-click ways to send it onward: copy the whole report to your clipboard,
   open a pre-filled issue in your browser, or open the folder holding the
   file. Bugs, ideas and plain reactions are all wanted equally.

   WHERE IT GOES: to the public P(Doom)1 issue tracker, where it is triaged
   and summarised before the developer reads it. It does not go to anyone's
   personal inbox. Your contact details are never included in the copied
   text -- only a name, and only if you tick the box.
