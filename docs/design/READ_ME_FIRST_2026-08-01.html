Three root causes worth knowing before you read the options

1. The settings screen is not missing content. It is folded.

settings_menu.tscn already contains every section: graphics quality, fullscreen, colorblind, keybinds, plus five code-injected toggles (leaderboard consent, launch ping, intros, hints, UI-layout A/B). An empty Spacer node and the Scroll both carry size_flags_vertical = 3, so the spacer eats half the fixed 800x600 column and the real content scrolls inside a ~200px window. The "empty Graphics section" you saw is the fold line. Two-line fix, about half an hour, un-hides six shipped sections. Do this whichever direction you pick.

2. The month review physically cannot show what you asked for.

You asked at [3:24] for "you planned 17 of 20, then reality intervened". MonthPlan.begin_month() destroys last month's spend and reserve data one call before the review renders. The information does not exist at draw time. Any fix needs a pre-reset snapshot first -- which reframes about half the proposals from "layout" to "capture the data, then lay it out".

3. The button sucks because it is wearing a costume.

It renders as [Q] Begin planning August 2017 (Free) because it is a generic event-choice button -- the (Free) is format_cost_summary({}) and the [Q] is just the first dialog key label. It is dark-grey 500x45 while END TURN is teal. And MainUI._input deliberately blocks SPACE and ENTER whenever a dialog is active, so the two keys a player tries first do nothing. Q working is an accident of the letter map, not a design.
