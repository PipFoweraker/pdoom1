Three bugs found incidentally, none of which anyone was looking for

The month review would have booked next month's rent, forever

MonthController.advance_tick() runs _open_plan_month() -- which charges the new month's office rent -- before the review is built. Reading state.money at render time books next month's rent against last month's delta, every month, in the same direction, and it looks entirely plausible. Caught only because A4 required reading the number.

The first rival report is guaranteed to be empty

game_manager.gd:796 seeds the drift baseline with the current value on first read, so the first month review always prints "capabilities flat" three times regardless of what rivals actually did. Your [3:58] complaint was even more right than it looked -- the first framed appearance of rivals is structurally information-free.

Related: the first UI element that ever names the concept is the WATCH screen's "Hide rival intel" toggle -- a mute button for a channel never introduced.

The F3 debug overlay has been crashing on every render

debug_overlay.gd reads state.seed, renamed to game_seed_str, aborting the Game State tab every time it drew. One-line fix, regression-covered, in #1104. Found by a test written for something else.
